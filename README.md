# CTF Challenges

CTF challenges I've designed and built myself, organized by category. Each
category folder has its own README with details on the specific challenges,
techniques, and how they were built.

## Categories

- [`forensics/`](forensics) - network forensics & packet analysis (Wireshark)
- [`pwn/`](pwn) - binary exploitation (stack overflows, ret2win)

More categories will be added here as they're built.

## Layout

Each category follows the same pattern:

```
<category>/
├── README.md       overview + table of challenges for this category
├── challenges/      what a participant gets: files + a short prompt, no spoilers
└── writeups/        my solutions, including flags
```
